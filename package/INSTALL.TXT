S3WIDE.DRV - widescreen / high-colour display driver for Windows 3.1 and 3.11
==========================================================================

What it is
----------
A Windows 3.1x display driver with two ways to drive the screen:

- On an S3 Trio64 asked for 1280x720 in 256 colours, it programs the S3
  chip directly (hardware mouse cursor).
- Everything else goes through the VESA BIOS (VBE 2.0 or later with a
  linear frame buffer): 8 bpp (256 colours), 16 bpp (65,536 colours) or
  32 bpp (16.7 million colours), at any resolution the BIOS lists, up to
  3840x2160 (4K) when the card or emulator offers it.

It needs Windows 3.1 or 3.11 in 386 Enhanced Mode and a 386 or later.
Nothing is stretched: Windows really runs at the resolution you choose.

Files
-----
S3WIDE.DRV    the driver
OEMSETUP.INF  lets Windows Setup install it and list its modes
VBEMODES.EXE  DOS tool that lists the VESA modes of this machine and says
              which ones S3WIDE.DRV can use (s3wide=yes)
DISPDIB.DLL   optional replacement for Video for Windows' full-screen
              display DLL that keeps 16:9 films 16:9 (see "Full-screen
              video")
S3WIDE-GUIDE.PDF  the full guide, with DOSBox-X settings and pictures
INSTALL.TXT   this file
SHA256.TXT    checksums of the files
VGA.3GR, VGALOGO.LGO, VGALOGO.RLE, VGASYS.FON, VGAFIX.FON, VGAOEM.FON,
CGA40WOA.FON, CGA80WOA.FON, EGA40WOA.FON, EGA80WOA.FON, DOSAPP.FON
              the standard Windows files Setup copies for a VGA-style
              display (DOS-window grabber, start-up logo, system and
              DOS-window fonts), so Setup needs no Windows disk

S3WIDE.DRV carries the cursors, icons and window bitmaps of Windows' own
VGA driver, and the files in the last entry are standard Windows for
Workgroups 3.11 files. Those parts belong to Microsoft: use this package
with your own licensed copy of Windows.

Before you install: keep a way back
-----------------------------------
1. Back up WINDOWS\SYSTEM.INI (for example: COPY SYSTEM.INI SYSTEM.BAK).
2. If Windows does not come up with the new driver, start the machine to
   the DOS prompt (do not run WIN), then restore the backup:
       CD \WINDOWS
       COPY SYSTEM.BAK SYSTEM.INI
   or edit SYSTEM.INI with EDIT and set   display.drv=vga.drv   in [boot].

Choose a mode
-------------
At the DOS prompt (before Windows), run
    VBEMODES > MODES.TXT
and read MODES.TXT. Each line is one mode, for example
    MODE 112   640x480   32bpp ... s3wide=yes
Pick a line that says s3wide=yes. If none do, the BIOS has no VBE 2.0
linear frame buffer and only the S3 Trio64 1280x720x8 mode can work.

Install with Windows Setup
--------------------------
1. Unpack the files into one folder, for example C:\S3WIDE (or a floppy).
2. In Program Manager open Main, Windows Setup. Choose Options, Change
   System Settings.
3. Open the Display list and pick the last entry,
   "Other display (Requires disk from OEM)...". Type the folder
   (C:\S3WIDE) and press OK.
4. Pick an "S3Wide ..." entry, for example "S3Wide 1920x1080 65K colors".
   Use a mode VBEMODES marked s3wide=yes.
5. Setup may ask whether to use the current or the new driver: choose
   New. If it asks for the "S3Wide display driver" disk or for a
   Windows disk (for example for CGA40WOA.FON), type the package folder
   (C:\S3WIDE): the package holds those files. It may ask more than
   once; give the same folder.
6. Restart Windows when Setup offers it.

To change the mode later, repeat steps 2 to 6 and pick another entry, or
edit Width, Height and Depth in the [s3wide.drv] section of SYSTEM.INI.

Every entry installs the same driver with small (96 dpi) fonts; Setup
writes display.drv=s3wide.drv, 386grabber=vga.3gr, display=*vddvga and
the [s3wide.drv] section.

Install by hand
---------------
1. Copy S3WIDE.DRV into WINDOWS\SYSTEM (not into WINDOWS itself).
2. Edit WINDOWS\SYSTEM.INI:

   In [boot] change the display line to
       display.drv=s3wide.drv
   Leave the other [boot] lines (386grabber=vga.3gr, oemfonts.fon=...,
   fonts.fon=..., fixedfon.fon=...) as they are for VGA.

   In [386Enh] keep
       display=*vddvga

   Add a new section with the mode you picked, for example
       [s3wide.drv]
       Width=1920
       Height=1080
       Depth=16

   Depth is 8, 16 or 32. Without this section the driver uses 1280x720x8.

3. Start Windows (WIN).

If the BIOS does not have the exact mode, the driver uses the largest
mode it can draw that is no bigger than the one asked for, at the same
depth if possible (on an S3 Trio64 it uses 1280x720x8 instead). The
Windows title bars and fonts are the normal VGA-size ones, so very large
modes make text small.

DOSBox-X
--------
For 4K and true colour use DOSBox-X's own card:
    [dosbox]
    machine=svga_dosbox
    [video]
    vmemsize=64
    vesa modelist width limit=0
    vesa modelist height limit=0
    allow high definition vesa modes=true
3840x2160 at 32 bpp needs 33 MB of video memory; 1920x1080x32 fits in
8 MB. The emulated S3 cards (svga_s3*) stop at 16 MB and 1920x1440.
At 4K the emulator spends much of its time drawing its own window;
[render] frameskip=10 helps on slower PCs.

Pictures and video
------------------
Windows bitmaps (BMP/DIB) at 1, 4, 8 and 24 bits per pixel are drawn at
every depth, including RLE-compressed 4- and 8-bit bitmaps. PNG, JPEG and
GIF need a viewer program that understands them; Windows 3.1 itself does
not. Video (AVI) needs Microsoft Video for Windows. Play it in a window
(Media Player, Device, Configure: Window) and maximize or size the window:
the driver stretches the frames itself in your desktop mode and colours.
In 256-colour mode the driver uses a fixed colour set (no palette
changes), so photos look coarser than at 16 or 32 bpp.

Full-screen video
-----------------
Video for Windows' "Full Screen" option (Media Player, Device, Configure)
is the fast way to play: it hands each frame to DISPDIB.DLL, which
switches the card to a small 256-colour mode (320x200 or 320x240) and
leaves the scaling to the monitor or the emulator. Microsoft's DISPDIB.DLL
lays the film out for a 4:3 screen, so on a 16:9 screen (DOSBox-X full
screen with aspect=false, a widescreen monitor) a 16:9 film comes out
stretched to about 21:9.

The DISPDIB.DLL in this package lays the film out for a 16:9 screen
instead: a 16:9 film fills the screen at its own shape, a 4:3 film gets
black bars at the sides. It uses the smallest 256-colour VESA mode that
holds the film at its full size (320x200 for a 320x180 film), so it is as
fast as the original. It works with any display driver.

To install it:
1. In WINDOWS\SYSTEM keep Microsoft's file:
       CD \WINDOWS\SYSTEM
       COPY DISPDIB.DLL DISPDIB.MS
2. Close Media Player and other video programs (or exit Windows), then
   copy DISPDIB.DLL from this package into WINDOWS\SYSTEM.
3. Play a film and choose Full Screen. Esc or a click stops it as before.
To go back, copy DISPDIB.MS over DISPDIB.DLL.

Settings (optional), in SYSTEM.INI:
    [dispdib]
    Aspect=16:9    shape of your screen (default). Use Aspect=4:3 for a 4:3
                   monitor or DOSBox-X with aspect=true, Aspect=16:10 for a
                   16:10 screen, Aspect=0 to keep the mode's pixels square
    Width=1280     use this mode instead of the smallest one (with Height;
    Height=720     slower, larger modes cost more per frame)
    Log=1          write the calls it gets to C:\DISPDIB.LOG
The shape is right on a full-screen display; a DOSBox-X window takes the
shape of the video mode unless its size is fixed.

Known limits
------------
- Full-screen DOS programs: the driver sets its mode again and Windows
  repaints when you come back. This was tested with a DOS session that
  ends by itself, on both paths; switching with Alt+Tab or Alt+Enter
  uses the same mechanism but was not exercised by hand.
- A windowed DOS box was not tested.
- All drawing is done by the processor; there is no 2D acceleration on
  the VESA path. Full-screen fills at 4K take about a tenth to half a
  second on an emulated ~100 MHz machine.
- 15-bit (5:5:5) and 24-bit packed modes are not used.
- Real hardware has not been tested; development used DOSBox-X 2026.08.31
  with Windows for Workgroups 3.11.
